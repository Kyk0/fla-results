Reviewer summary · Original run status · Recorded decisions · Adder weights · Viper weights

The original final report was not written. The strict original claim about shear on unseen gaits remains incomplete because the replication using the old pressure blocks and the third held-out gait were cut.

1. How many pressure points?

More pressure points help on seen and unseen gaits, but the advantage reverses when the sole model changes.

2. Does shear help?

Four shear vectors improve terrain recognition in the tested comparisons; the minimum number of vectors was not tested.

3. Does shear help more on SONIC?

The tested unseen-gait results do not establish a larger shear benefit for SONIC.

4. Which layout should we choose?

No tested layout passes the original robustness rule under the eight-model sensor average used here.

5. Does it hold on real robots?

Three-axis force helps on QCAT but not PUTany; these quadruped recordings do not validate a humanoid pressure map.

Limits and checks

The simulated foot is a rigid box. Small sensing footprints overcount concentrated edge loads; the foot mask misses loads at box corners. One centre-of-pressure check failed. Both contact-policy training attempts failed their improvement rule.

Some original status paragraphs and real-data comparison rows remain stale or pending. The reviewer summary preserves these gaps and the difference between nominal-sensor and seen-gait scores.
